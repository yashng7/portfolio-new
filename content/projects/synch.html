System Summary

Synch is a real-time event monitoring and alerting SaaS platform engineered to ingest application events via REST APIs, stream live telemetry to a web dashboard over WebSockets, and dispatch instant notifications to Discord channels.

Architectural Overview

Designed for engineering teams and indie SaaS operators, Synch provides a single pane of glass for critical business and infrastructure events—such as new user signups, payment failures, or production exceptions—delivered with sub-second latency.

Core Subsystems & Capabilities

01 // Real-Time Telemetry & Alerting

  • Live WebSocket Event Stream: Push-based dashboard updates that surface incoming events immediately without manual polling.
  • Instant Discord Webhook Dispatch: Automated rich-embed alerts routed directly to team Discord servers on critical events.
  • Custom Event Categories & Metadata: Structured JSON payload ingestion supporting arbitrary key-value attributes and severity tags.
  • Time-Series Analytics Dashboard: Aggregated event volume charts and category breakdowns across daily, weekly, and monthly windows.

02 // Multi-Tenant SaaS Platform

  • API Key Provisioning & Quota Enforcement: Per-tenant bearer token authentication with monthly event ingestion rate limits.
  • Clerk Authentication & Workspace Security: Seamless OAuth/email sign-in with protected dashboard routes.
  • Stripe Subscription Billing: Automated plan upgrades unlocking higher event quotas and custom categories.
  • PostgreSQL High-Throughput Storage: Indexed event tables optimized for fast time-range filtering and pagination.

Technical Specification

  • Frontend & Routing: Next.js App Router, TypeScript, Tailwind CSS, shadcn/ui components.
  • Backend & Real-Time: Next.js API Routes, WebSocket connections, Discord REST API integration.
  • Database: PostgreSQL with type-safe ORM queries and indexed timestamp lookups.
  • Auth & Billing: Clerk Authentication and Stripe webhook-driven entitlement management.

Engineering Challenges & Solutions

Reliable Event Ingestion with External Webhook Fan-Out: When an external service posts an event to Synch's ingestion API, the endpoint must validate the API key, persist the event to PostgreSQL, broadcast to active WebSocket clients, and trigger Discord notifications without blocking the caller. Decoupling validation and persistence from downstream notification delivery ensured fast API response times and resilient alert delivery.
