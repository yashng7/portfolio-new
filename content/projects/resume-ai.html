System Summary

ResumeAI is a full-stack AI SaaS platform that streamlines technical resume authoring through Gemini AI content generation, interactive drag-and-drop section ordering, debounced cloud auto-save, and multi-tier Stripe billing.

Architectural Overview

ResumeAI combines a multi-step React Hook Form state machine with real-time live preview rendering. Users can generate tailored experience bullet points via the Gemini AI API, reorder sections with `dnd-kit`, and export print-ready PDFs.

Core Subsystems & Capabilities

01 // AI Authoring & Interactive Editor

  • Gemini AI Auto-Fill Pipeline: Context-aware prompt orchestration that generates high-impact resume summaries and experience bullets.
  • Drag-and-Drop Section Ordering: Smooth, accessible section rearrangement powered by `dnd-kit` with instant preview synchronization.
  • Multi-Step Form State Machine: URL-synchronized step navigation built with React Hook Form and Zod schema validation.
  • Debounced Cloud Auto-Save: Background state persistence ensuring zero data loss during editing sessions.

02 // SaaS Infrastructure & Monetization

  • Multi-Tier Stripe Subscriptions: Webhook-synchronized subscription gates for Free, Pro, and Plus feature tiers.
  • Cloud Asset Storage: Profile photo and document asset management backed by Vercel Blob storage.
  • PostgreSQL Relational Persistence: Normalized schema storing user profiles, resume versions, and subscription entitlements.
  • High-Resolution PDF Export: Instant client-side print and PDF generation preserving custom color themes.

Technical Specification

  • Frontend Architecture: Next.js 15, React Hook Form, Zod, `dnd-kit`, Tailwind CSS, shadcn/ui.
  • AI Integration: Google Gemini AI SDK via server actions and streaming endpoints.
  • Database & Storage: PostgreSQL, Prisma ORM, and Vercel Blob object storage.
  • Payments & Auth: Stripe Checkout + Customer Portal webhooks and secure user authentication.

Engineering Challenges & Solutions

Zero-Lag Live Preview with Background Persistence: Updating a complex document preview on every keystroke while syncing to PostgreSQL can cause input lag or database write amplification. Implementing optimistic local state paired with a debounced dirty-field sync queue kept typing latency under 16ms while minimizing database writes.
