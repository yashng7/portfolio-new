System Summary

Minimal CV is a lightweight, print-engineered developer curriculum vitae and portfolio system built with Next.js, TypeScript, and Tailwind CSS—designed to render identically on high-DPI screens and exported A4/Letter PDFs.

Architectural Overview

Most web portfolios break when printed to PDF, while static PDFs lack interactivity and dark-mode ergonomics. Minimal CV unifies both mediums into a single structured data source with dedicated screen and `@media print` layout engines.

Core Subsystems & Capabilities

01 // Dual-Medium Rendering Engine

  • Print-First Stylesheet Architecture: Dedicated `@media print` rules that strip navigation chrome and format typography for single-page PDF export.
  • Zero-Latency Theme Persistence: Instant dark/light mode switching powered by `next-themes` with zero flash of unstyled content.
  • Responsive Grid Topology: Fluid layout adapting seamlessly from mobile viewports to desktop monitors.
  • Minimal Dependency Footprint: Engineered for 100/100 Lighthouse performance and instantaneous First Contentful Paint.

02 // Structured Dossier Modules

  • Executive Identity Header: Direct contact endpoints, location metadata, and social verification links.
  • Chronological Experience Log: Structured role timelines with company badges and impact summaries.
  • Education & Certifications: Verified academic credentials and technical certifications index.
  • Categorized Skills Matrix: Scannable technology tags grouped by engineering domain.

Technical Specification

  • Framework: Next.js with Static Site Generation (SSG).
  • Language: Strict TypeScript configuration for structured resume data schemas.
  • Styling & Print Engine: Tailwind CSS with custom print-media utility rules.
  • Theming: `next-themes` with system preference detection.

Engineering Challenges & Solutions

deterministic Web-to-PDF Pagination: Browser print engines often slice cards or headings awkwardly across page boundaries. By implementing strict `break-inside: avoid` rules and calibrated print typography scales, Minimal CV exports clean, recruiter-ready PDFs directly from the browser.
